# Protótipo Inicial

Este protótipo inicial foca na página principal com:
- Navegação superior clara e elegante.
- Hero com título forte e mensagem de valor.
- CTA em destaque para participação na liga.
- Área de apresentação de atividades e propósito.

O design deve usar:
- Azul escuro como base sólida.
- Dourado para acentos e chamadas à ação.
- Branco para tipografia e espaços de respiro.

Objetivo: criar uma identidade visual moderna, sofisticada e que passe confiança para estudantes e visitantes.
